# Home page redesign

The site usvoting.info is in need of a redesign. Presently, the home page consists of a series of 51 cards, each of which provides a summary of the registration and voting requirements for each of the 50 states and Washington D.C.

While there is an All News page that provides news about voting in each state, there is no news on the home page.

What I would imagine is taking perhaps 5-10 of the most recent news items from the All News page and displaying them on the home page. Each item would contain a headline that serves as a link to the full news article, followed by the date, the source of the news item, and a 2-character abbreviation for the state from which the news item is from and that link would go to the news page for that state.

And this set of news items could be followed by a list of links to the news for each state, with the link being the 2-character state abbreviation. For example, there would be a link "CA" that would take the user to the news for California.

The page would then continue on with the summaries of the registration and voting information cards, one for each state and DC. This set of cards could also be preceded with a list of links, a 2-character state abbreviation linking to that state's detail page.
