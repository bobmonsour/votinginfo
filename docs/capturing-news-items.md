# Capturing per-state election news

## Updating the voting-research skill to capture news items

I would like for the voting-research skill to be updated to capture up to 5 of the most recent news items related to the election in each state. These can be from reputable media outlets as well as non-profit research organizaations such as the Brennan Center for Justice. The news items should be stored in a structured format, including the title, source, a link to the item, publication date, and a brief summary of the content. This information will help provide context and insights into the election landscape in each state.

This structured data should be stored in a json file, noting the date of the run of the skill along with the items noted in the paragraph above.

Then, for each state, on each state detail page, below the Sources section, there should be a new section called "Recent News" that lists the captured news items in a readable format, including the title (as a hyperlink to the original source), the source name, publication date, and the brief summary. This will allow users to quickly access relevant news and stay informed about the latest developments in each state's election process.
