# Adding a glossary of terms

On the About page, I would like to have a glossary of terms, with definitions of the data items included in each state's data. The Glossary would be a section on the About page below the Research Methodology section.

This would consist of a 1-2 sentence definition of each of the following:

- Registration Deadline
- Same-Day Registration
- Online Registration
- Early Voting
- Absentee Voting
- Mail-In Voting
- Voter ID Requirements
- No excuse required
- Excuse Required Mail-In
- Felony Voting Rules
- Proof of Residency
- Proof of Citizenship
- Valid photo ID
